## ✅ 프로젝트 소개
예비 개발자들이 부트캠프 후기 공유, 스터디원 모집, 일정 관리에서 겪는 어려움을 해결하기 위해 개발자 전용 커뮤니티 플랫폼 GrowTogether를 기획, 구현 했습니다. 이 플랫폼은 단순 정보 제공을 넘어 스터디 지속률 강화와 실질적인 협업 경험을 목표로합니다.
